### Problem
242. Valid Anagram
    
Given two strings s and t, return true if t is an anagram of s, and false otherwise.



### Thinking

- 找到字母異位詞 -> 用陣列寫法做計數與抵銷

### Code
```csharp
public class Solution {
    public bool IsAnagram(string s, string t) {
        int sl = s.Length;
        int tl = t.Length;
        if (sl!=tl) return false;

        int [] a = new int[26];

        for (int i=0; i < sl; i++) {
            a[s[i] - 'a']++;
            a[t[i] - 'a']--;
        }

        foreach(int i in a) {
            if (i!=0)
            return false;
        }

        return true;
        
    }
}
```
